# 🛍️ Store Sales Analysis Excel Dashboard

## Overview
This project analyzes retail store sales data and presents key business insights through an interactive Excel Dashboard. The dashboard helps track revenue, orders, customer behavior, sales trends, and product performance using dynamic visualizations.

## Dataset
The dataset contains store transaction records, including customer demographics, product categories, sales channels, order details, revenue, and geographic information. The data was cleaned and transformed before analysis to ensure accurate reporting.

## Business Questions Solved
- What is the total revenue generated?
- How many orders were placed?
- Which category sells the most?
- Which sales channel generates the highest revenue?
- What are the monthly sales trends?
- Which age group contributes the most revenue?
- What are the top-performing states and cities?
- What is the average order value?

## Key Features
- Data Cleaning & Transformation
- Pivot Tables & Pivot Charts
- KPI Tracking
- Revenue Analysis
- Customer Segmentation
- Sales Trend Analysis
- Interactive Slicers & Filters

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Design
